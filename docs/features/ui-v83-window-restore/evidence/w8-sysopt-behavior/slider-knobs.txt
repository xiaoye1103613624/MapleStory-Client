推论
  1) 鼠标/HP/MP 三条：存值 10、钮在行程 51.0% ⇒ 是**索引刻度**而非百分比。
     候选 0..19（10/19 = 52.6% ⇒ 预测左沿 166.4，Δ2.4 px）
     候选 0..20（10/20 = 50.0% ⇒ 预测左沿 162.5，Δ1.5 px）
     ⇒ 两档都在 2~3 px 内，**这张帧分辨不出上限到底是 19 还是 20**；本包按 0..19 反推
       （percent * 19 / 100），最大偏差 1 档，手感层面无感。要坐实只能改值后抓帧。
  2) 画质：钮在 89.3% 而 soVideo = 3 ⇒ 与索引/百分比都成不了线性关系，
     原生是**离散档吸附**；档位总数与每档吸附位置**无证据** ⇒ 见 README §4 预留 2。
