## 7. 两条「形状」教训

1. **加载器 trim 掉了值两端空白**（[Util/Locale.cpp:15-23](../../../../../Util/Locale.cpp#L15)），所以
   `前置任务: ` / ` 职位{}` / ` 的商店` 这三类「空格在边缘」的字面量**不能原样进 ini** ——
   空格要么挪进占位符两侧（`{} 的商店`），要么留在代码拼接里。首版按「值 = 原字面量」直写，
   会在界面上静默少一格；两条尺都不报（值对得上、arity 也对得上），只有读加载器才看得见。
2. **中文后置词 ≠ 英文所有格**：`owner + " 的商店"` 若拆成「名字 + 后缀键」，英文会渲染成
   `Bob 's Shop`。故 `merchant.owner_shop = {} 的商店` / `{}'s Shop` 整句进键 ——
   这正是 `Locale::format` 存在的原因（语序是语言属性），本批把它当成判据而不是偏好。
