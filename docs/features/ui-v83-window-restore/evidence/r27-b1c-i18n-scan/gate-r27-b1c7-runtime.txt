## 判据（仪器行，非像素）

```

```

| 字段 | 含义 | 证明了链路的哪一段 |
| --- | --- | --- |
| `gen=2` | 代次从 1 跳到 2 | 主循环 `reload_if_changed()`（MapleStory.cpp:240）→ 捕获 xy-config mtime → `Locale::reload()`（Configuration.cpp:551）→ `++gen` |

| `version.prefix=LANGEN {}` | 新代次 primary 已是 en 侧 | 沙箱 en-US.ini 预置标记值（zh 侧保持 `Ver. {}`）⇒ 不是「读了同值的另一份」，语言表真的换了 |
