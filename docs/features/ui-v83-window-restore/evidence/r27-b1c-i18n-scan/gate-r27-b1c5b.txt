## 5. 新增两把自证尺（本批立，负对照验过，**收尾时已并进 `tools/`**）

### 5.1 占位符 arity（`tools/check_placeholder_arity.py`，读数详单 [gate-r27-b1c5b-arity.txt](gate-r27-b1c5b-arity.txt)）

`Locale::format` 只认第一个 `{}`、`format_all` 按序填；ini 值占位符与实参个数不匹配**不报错**，
只在界面上留裸 `{}` 或把值拼到句尾。新尺对全站调用点配平实参列表与 ini 占位符数，
`Locale::enum_key("equip.stat.", …)` 这种运行时拼键的整族查：

```
python tools/check_placeholder_arity.py --both
arity 校验调用点 = 318 | 不合格 = 0 | 判据 = locale/zh-CN.ini + locale/en-US.ini
```

负对照两轮（改坏 `locale/zh-CN.ini` 三条值：`equip.stat.STR` 加占位、`delivery.row_meso` 加占位、
`delivery.fee_calc` 减占位）⇒ 三条全部按 `文件:行 + 现值` 指出，跑完 ini 按备份原样还回（md5 一致）。
第一轮**因破坏脚本静默 no-op 只验到两条**，第二轮起脚本自证三条落地 —— 详见详单。

### 5.2 值保真（`tools/check_value_fidelity.py`，读数详单 [gate-r27-b1c5b-fidelity.txt](gate-r27-b1c5b-fidelity.txt)）
