== 结论 ==
原生装备/物品 tooltip 背板 = 实心 1.0α（判据成立）
1) 同色跨底对照（决定性）：背包tooltip内bg均值 压在米色背包窗(238,238,221)上=(79.2,79.2,119.6)；压在深色游戏画面(~30,25,55)上=(78.6,78.7,124.2)。ΔR=0.6；若0.9α应差≈21。反推透出系数≈0.3% ⇒ α≥0.99。
2) 平坦区std：面板内bg像素std=(2.3,2.3,3.3)（bag）/(2.8,2.8,2.4)（装备tip压在亮绿草地上，R=G严格相等、无绿染）；面板外紧邻画面std=(30.7,27.5,15.4)/(56.2,52.2,36.7)/(49,49,57)。内std非零系36px周期拼贴缝(85,85,130)/(68,68,108)固定纹理（各行同x复现），与背后画面无关。
3) 边缘带：无外描边、无投影（紧邻面板的游戏像素未被压暗，x252+为原色岩石(34,28,57)）。背板自带1px亮边(85,85,130)、顶行1px(68,67,106)、底行1px(17,18,47)；左/上缘存在1px透出缝隙（x31/x131、y86），为原生拼贴缝伪影，不必复刻。
4) 我方对照：当前客户端截图/鼠标悬浮道具上显示的信息.png 中 tooltip 背板整体不可见（全图仅76个bg色散点，文字区实测为纯米色窗底(238,238,221)），该帧无法量化我方0.9α效果——如实报告，不充数。
=> 我方应把装备tooltip背板 α 从 0.9 改为 1.0；边框无需加外描边/投影。
