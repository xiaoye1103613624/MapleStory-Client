## 1 三层底板叠放顺序：逐带配准钉死

整窗 SAD 配准在 Messenger 上是**误导**的：`backgrnd` 与 `backgrnd2` 在 y0..25 完全同色，
`backgrnd` 的 y0..239 又被 `backgrnd2` 盖住，所以整体 SAD 会同时给两个候选。
改用**分带配准**（只看某一层未被遮挡的带），在窗口原点 (0,6) 处结果：

| 带 | 取自 | SAD |
| --- | --- | --- |
| y0..104 | `backgrnd2` | 13.15 |
| y148..239 | `backgrnd2` | **6.06** |
| y240..363 | `backgrnd` | **5.59** |
| y0..104 | `backgrnd`（预期更差：被盖住） | 30.98 |

偏移 ±1 行时全部劣化（y=5 → 23.61/23.89/20.91；y=7 → 24.59/24.42/17.54），
所以窗口原点就是 (0,6)，且**预测的非对称出现了**：被盖住的 `backgrnd` 上半 SAD 明显更差。

⇒ 结论：`backgrnd(0,0) → backgrnd2(0,0) → backgrnd3(55,22)` 的现有绘制顺序**是对的**，
不需要改。`backgrnd3` 另有一处独立佐证：参考图里白色页签的上下黑边在
local y24 / y41、x58..231，而 `backgrnd3` 画在 (55,22) 正好罩住 x55..238 / y22..43 ✓。

### 8.1 ESC 收不了窗（与 B5-2 同一条根因，第三次踩）

焦点在输入框时，`UI::send_key` 把**所有**键整条交给 `focusedtextfield->send_key`
（[IO/UI.cpp:202](file:///absolute/path/IO/UI.cpp#L202)），本窗的 `send_key` 走不到，
所以 `if (pressed && escape) toggle_active()` 那段永远不执行。修法同
`UIWhisperTargetDlg`：把 ESC 挂到字段的回调上
（`Textfield::send_key` 的 `default:` 分支查 `callbacks`，
[IO/Components/Textfield.cpp:236](file:///absolute/path/IO/Components/Textfield.cpp#L236)）。
`toggle_active()` 里已有 `chat_input.set_state(DISABLED)`，而 `set_state(DISABLED)`
自己会 `UI::get().remove_textfield()`（[IO/Components/Textfield.cpp:80](file:///absolute/path/IO/Components/Textfield.cpp#L80)），
所以收窗后焦点不会留在死字段上。

### 8.2 顺带同源：底板画 4 枚名牌，模型只留 3 格

`NameBar/0..3` 是四张不同色的图（灰/蓝/红/绿，三上一中），底板也确实画四枚；
但 `SLOT_COUNT = 3` 让 `set_member(pos=3)` 直接 return ⇒ 第四枚名牌永远是空的。
按「绘制面与取数面同源」收敛成 `SLOT_COUNT = 4`（pos≥4 仍拒，不会越界）。

### 12.2 「点空名牌不出字」是实例环境问题，不是功能缺陷

第一版复验（帧 `_b53ms_*`，05:31）里聊天历史区一片空白，差点误判成 draw 侧 bug。
临时文件探针（已删，摘录存 `b53-frames/_b53_dbg_clickpath_excerpt.txt`）先证明点击链是通的：

```
send_cursor clicked=1 active=1 in_room=0 pos=(500,80) cur=(558,197)
  HIT slot=0 rel=(58,117) occupied=0
append_chat before n=0 line='Not in a Maple Messenger room yet.'
```

真因：**字体路径是相对 cwd 的**（`Configuration.h:520` 默认 `fonts/SimHei/simhei.ttf`，
`GraphicsGL.cpp:228` 直接 `FT_New_Face`），第二实例的运行目录没有 `fonts/` ⇒
`addfont` 全批失败 ⇒ 该实例里**任何** FreeType 文字都不画（名牌、边框、ENTER 徽标这些
位图照常，所以看上去「只有字没了」）。补 `fonts/` 后同一条链路立刻出字
（`_b53ms2_04_typed_en.png`）。`locale/*.ini` 同理是 cwd 相对（`Util/Locale.cpp:87`），
新实例也要带一份。

顺带修了读数脚本自身的坑：`ink_rowseg` 原写 `int(np.sum(dev) > th)`（先求和再比较），
每行恒真/恒假，把「已出字」读成空列表；正确是
`int(np.sum(dev > th))`（先数超阈像素再比）。
