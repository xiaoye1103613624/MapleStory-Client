2. **FieldHasSky**：`WeatherSkyTable.h` 含 `kNoSkyMaps`（264）+ `field_has_sky` / `field_gate`；装图写入 `State::allow_falling` / `allow_tint`。
3. **渲染门禁**：粒子/地面/闪电 → `allow_falling`；夜色/路灯 → `allow_tint`；水下可 tint 不落雨。
4. **彩虹**：`rainbow_ms_carry_` 按 ms 累加再折秒。
5. **0x373F**：`Lamps::apply_preview` 接 GM 预览。
