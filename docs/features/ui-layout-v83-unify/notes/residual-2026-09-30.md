# UI 全链路残留修复（登录→局内）

> 状态：已实现（2026-09-30）；**同日续修** 乱码/双框/卷轴/属性卡/黑屏  
> 适用：BeiDou gms083 / 1280×720 / `data.format=img`  
> 部署：`E:\MXD\BeiDou-Client-xy\`

## 续修根因

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 账号密码乱码 | `text_shift(1,11)` 与 Text linespace 叠基线，字形落在槽外 | `text_shift(2,0)` |
| 登录后双提示框 | 公告气球 + 英文 chatballoon | BeiDou 禁画英文气泡 |
| 频道卷轴位置错 | 滑距 80 过大；origin 脏值 | 滑距 24；origin 消毒 |
| 属性卡无背景/错位 | origin 偏移 + 旧单列坐标 | 清零 origin；按 charInfo1 双列重标 |
| 进游戏黑屏有 BGM | 登录大图占满 atlas，装图回收打乱 | 进游戏也 `unload_atlas` |
