## 1. 为什么要反推

`CUITitle::OnCreate`（0x62054A）给出的按钮/输入框坐标都是**相对 CUITitle 窗口**的：

| 控件 | IDA 窗口内坐标 | 尺寸 |
| --- | --- | --- |
| BtLogin（连接） | (213, -5) | 95×45 |
| BtLoginIDSave（保存账号） | (37, 74) | 51×23 |
| BtLoginIDLost（密码修改） | (144, 73) | 59×23 |
| BtPasswdLost（找回密码） | (226, 74) | 56×23 |
| BtNew（新的帐户） | (14, 122) | 92×38 |
| BtHomePage（网站） | (114, 120) | 93×38 |
| BtQuit（结束） | (214, 120) | 81×40 |
| 账号输入框 | (67, 12) | 132×15 |
| 密码输入框 | (67, 40) | 120×15 |
| 保存账号勾选框 | (12, 73) | — |

但 **CUITitle 窗口自身的屏幕位置在反编译中未确定**（见 `notes/ida-coords.md` §6「父窗口帧仍未唯一确定」）。
此前实现把「木牌左上角」直接当成窗口原点，结果整块面板相对木牌偏左上。

## 2. 实测方法

1. 从 `UI.nx` / `Map001.nx` 解出位图（`tools/nx_inspect.py`）：
   - 木牌 `Obj/login.img/Title/signboard/0/0` 368×236，origin (184, 118)
   - logo `Obj/login.img/Title/logo/0/0` 397×219，origin (198, 109)
   - 7 个按钮的 `Login.img/Title/<名>/normal/0`
2. 在两张截图上做**掩码归一化互相关**（只用位图不透明像素；透明像素不参与打分，
   否则会被背后的地图画面污染）。工具先自检：把木牌贴到合成画布 (500,200)，
   定位结果 (500,200) ncc=1.000。
3. 用 logo 反推地图相机 `viewpos`，得到木牌的屏幕左上角，再把按钮位置换算成
   「按钮 − 木牌左上角」。

## 3. 结果（参考客户端 1280×720）

木牌左上角 ≈ (564, 272)（由 logo 反推 viewpos=(611,369)，再用 sign 公式得到）：

| 按钮 | 实测（相对木牌左上角） | IDA 偏移 | 差值 |
| --- | --- | --- | --- |
| BtLogin | (271, 11) | (213, -5) | **(58, 16)** |
| BtLoginIDSave | (95, 90) | (37, 74) | **(58, 16)** |
| BtLoginIDLost | (202, 89) | (144, 73) | **(58, 16)** |
| BtPasswdLost | (284, 90) | (226, 74) | **(58, 16)** |
| BtNew | (72, 138) | (14, 122) | **(58, 16)** |
| BtHomePage | (172, 136) | (114, 120) | **(58, 16)** |
| BtQuit | (272, 136) | (214, 120) | **(58, 16)** |

7 个按钮**逐个一致**，其中 6 个匹配度 ncc = 1.000（BtLogin 0.939，其贴图被面板遮挡了一部分）。

交叉验证：
- 保存账号勾选框：窗口内 (12,73) + (58,16) → 木牌相对 (70,89) → 预测屏幕 (634,361)，
  参考图实测 ≈ (635,362) ✓
- 账号输入框：窗口内 (67,12) 132×15 → 木牌相对 (125,28)；参考图实测 ≈ (118..258, 23..45) ✓，
  正好落在木牌自带的深色内嵌输入区（约 x 105..255, y 30..48）内

本实现截图（同一算法）：7 个按钮实测差值恒为 (0, 0)（即面板原点 = 木牌左上角），
所以需要把面板原点整体 +(58, 16)。

## 4. 结论（已落到代码）

`IO/UITypes/UILogin.cpp`：

```cpp
const Point<int16_t> TITLE_WINDOW_OFFSET(58, 16);
panel_pos = sign_topleft + TITLE_WINDOW_OFFSET;
account_pos  = panel_pos + Point<int16_t>(67, 12);
password_pos = panel_pos + Point<int16_t>(67, 40);
check_pos    = panel_pos + Point<int16_t>(12, 73);
// 按钮统一走 panel_pos + IDA 偏移
```

输入框随之落在木牌自带的输入区上（无需再单独调白底方框的位置）。

复现命令（掩码互相关脚本在临时目录，核心逻辑）：
先用 `nx_inspect.py image` 导出木牌/logo/按钮位图，再对截图做
`ncc = Σ(win-mean)(t-mean_t) / (‖win-mean‖‖t-mean_t‖)`，只统计位图 alpha>200 的像素。
