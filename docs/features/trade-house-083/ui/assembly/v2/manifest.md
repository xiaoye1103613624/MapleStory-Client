# UI manifest — assembly / v2

- 样式来源：原生
- scale：1x
- 目标尺寸：
  - `BrowseFilterExpand` 终稿区 **640×480**（PSD 画布 860×500，含右侧素材区）
  - `ListAuction` 终稿区 **640×420**（PSD 画布 860×440，含右侧素材区）
- 状态列表：本目录为**拼装预览**；控件态取自既有 `ui/*/v1/`（normal / selected / disabled 等），不全态重生成
- 样板：无（v083 经验基线）；零件复用同功能 `ui/*/v1/`
- 采样路径 / 客户端：未实测（见 `notes/client-path.md`）
- 目标节点路径：待定（`UITradeHouse`）
- psd：本目录各场景 `.psd`（终稿区 + 素材区分层；可编辑文字层 + 小组件位图层）
- 组件列表（复用）：
  - chrome · tabs · list · buttons · grid · inputs · feedback（均 v1）
- 生成说明：
  - **浏览·装备筛选展开**：沿用既有 `BrowseFilterExpand` PSD（组件拼装 + 中文占位），校验尺寸 640×480 并重导出 PNG
  - **上架·拍卖**：由 `assembly/v1/ListForm.psd` 派生 → 模式切「拍卖」、时长换 `Combo_disabled` 只读「1小时」、数量锁定示意 `1`、起拍价字段、费用预估与「不可下架」提示；中文标签以 SimSun 文字层保留
- 验收：§13 拼装可改版；PSD 分层；未覆盖 v1；无业务代码 / 无 DDL / 无 commit

## 编码策略（UTF-8 预览 / 入库 GBK）

| 阶段 | 策略 |
| --- | --- |
| **预览 / 文档 / PSD 文字层** | 使用 **UTF-8** 中文占位（本 manifest、PNG 预览所见文案、PSD `textItem`） |
| **客户端入库 / 插件 UI 字符串** | 经典 v083 客户端多为 **GBK / CP936**；入库或写插件文案时须转码，**禁止**把 UTF-8 字节直接塞进 GBK 期望的节点/封包 |
| **本版范围** | 仅归档预览图与可编辑 PSD；**不**写入 live `.img`；正式文案表另开任务时再按 GBK 落库 |
