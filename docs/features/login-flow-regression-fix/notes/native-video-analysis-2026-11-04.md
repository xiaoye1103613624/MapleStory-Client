## 频道页（UIWorldSelect）
- 卷筒从屏幕顶边降下（4.0→4.4s），纸向下逐步放卷；IMG scroll/0 四帧 250/50/50（350ms）为准，
  视频中放卷偏慢是服务器等待期，动效本身按 IMG 时长播。
- 末帧 513x401 定格常驻（纸底带卷曲边），chBackgrn 449x233 叠加其上；静止态不是平面羊皮纸。
- 公告牌：独立小牌（约176x67 @1280空间），位于大羊皮纸左侧、右缘略压纸边（纸左缘+15px），
  纵向对齐纸顶+28。纸卷完成时与内容同步淡入（6.53s 帧已出现而频道列表尚未出现），无独立卷开动画。
- 频道→选角过渡：整个频道层（卷筒+纸+列表+公告）作为刚体向下滑出屏幕（channel_slide 真实播放），
  选角页在其后揭示。

## 选角页（UICharSelect）
- 静止态 = scroll/2 末帧 217x193 常驻（顶部小卷筒+垂纸+底卷边），charInfo 内容 183x151
  画在纸内 +(17,39)。原生不隐藏卷轴，无 ColorBox 底垫（纸即底）。
- 详情面板锚点（1280空间，视频12s帧）：面板滚筒顶 ≈(385,155)。

## 建角页（两态）
- 职业团选择页：标题横幅"选择您喜欢的角色"居中顶部；三组职业剪影横排（左/右组灰度、选中组彩色）；
  深棕描述面板（金边）横贯中部，右下角内嵌"选择"钮+右侧星值列。
- 命名页：只有"角色名称"吊牌木板（挂杆下，含输入槽）+ 板下 确定/取消 两钮；
  无性别下拉、无欢迎文字、无羊皮纸（桌面截图《创建冒险家角色页.png》同证）。
- 过渡：地图纵向平移（相机下移），命名板随后淡入。
- 左侧菜单常驻：查看世界地图(仅频道页)/查看所有角色/回到首页，均贴屏幕左缘。

- 背板 = 深蓝实心（约85,85,130）+ 1px 灰边框，α约1（与实测一致）。
- 道具 tip 原生布局：物品名 → 图标(左)+要求行(右) → 职业列表横排一行
  （新手 战士 魔法师 弓箭手 飞侠 海盗，非叠绘）→ "装备分类：上衣"分类行 → 属性行。
  之前"叠绘为原生"的 SAD 结论不成立，应改横排；分类行是原生功能，需接入。
- 技能 tip 原生布局：图标在左上(32x32+IconBase底板)，标题在图标右侧、maxwidth 内不溢出，
  描述在标题下方同栏，分隔线后 Next Level 全宽。
