# 地图背景高分兜底：一次已证伪并回滚的尝试

> 状态：**已回滚**（`f810229f` 实现 → `436dac9d` revert）
> 结论：`type=0` 单张层做「半透明淡出复制」在本端不可行，**不要重试**。

## 1. 尝试了什么

`f810229f` 在 `Background::draw_normal_with_fade`（MapBackgrounds.cpp:150-293）对所有 `type=0`（NORMAL）层：

- 按 `dim_x` / `dim_y` 向左右上下各复制最多 3 / 4 份；
- 奇数级水平镜像翻转；
- 逐级 `opacity *= 0.55^k`。

用户拍板前提：分级代码兜底 / 半透明淡出 / 全局 / 不预留开关。

## 2. 为什么错（已证实，非推测）

1. **`type=0` 语义**：NORMAL 是完整场景元素（远山、树带、建筑、长椅、登录场景树），不是可平铺纹理。按 `dim` 平移复制 = 双胞胎重影；半透明递减只让重影变淡，不消除重复。
2. **全局生效放大了伤害**：`LoginBackground` 内嵌 `MapBackgrounds`（IO/LoginBackground.h:132），所以登录场景同样被复制 → 用户「从登录界面就出现混乱」。
3. **「半透明淡出」前提不成立**：淡出只适用于可重复的连续纹理（云/雾/渐变），对有明确轮廓的场景元素必然糊成重影。
4. **「边缘拉伸」用现成 API 做不到**：`Texture::draw` 的 `vertical/horizontal` Range 在 `GraphicsGL::draw`（GraphicsGL.cpp:911-925）是**裁切**（`offset.top += first; bottom -= second`，目标 rect 同步收缩），不是「取边缘行拉伸到目标尺寸」。要真做边缘拉伸须改 Graphics 公共绘制原语，属高风险改动。
