# r801 — Plant/Raise / FamilyTree / Party / Buddy / Messenger / PartySearch

## SoftKey
- Plant / Raise 构造与 SoftKey `U`：USE/ETC 选中直接 UseItem
- FamilyTree SoftKey `U`/`S`/`X`：无树选中时用 CharInfo
- Party Leader/Expel：无行选中时用 CharInfo cid
- BuddyList Accept/Delete/Reject：CharInfo cid 兜底
- Messenger SoftKey `D` Decline：CharInfo 名兜底
- PartySearch BtReg：直接 `start_search()`（与 SoftKey `S` 对齐）
