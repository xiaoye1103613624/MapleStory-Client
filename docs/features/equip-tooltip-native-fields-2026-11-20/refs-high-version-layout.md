## 3. 潜能计算逻辑（BWIKI /maplestory/潜能，action=raw，2026-11-20 抓取）

来源：https://wiki.biligame.com/maplestory/潜能 （外部资料，仅作数据参考）

### 3.1 条数规则
- 一件装备潜能条数**恒 3 条**，部分装备第三条为隐藏（可用印章可见）。
- 第一条与潜能等级直接相关（除特殊魔方外必定为当前等级）；第二、三条与潜能等级无关。
- 等级链：一般物品 C（不提供潜能）→ 高级 B → 史诗 A → 传说 S → 传说极品 SS。
- 可能组合示例：S 级三潜能可为 SSS / SSA / SAA / SAB / SBB / SB-B-；不可能 ABB（第一条必须 S）。

### 3.2 数值公式（装备等级档 × 潜能等级 → 属性值）
- 力量/敏捷/智力/运气 固定值：B- +1/+2/+3/+4/+5/+6（0-20/21-40/41-50/51-70/71-90/91-150），B 翻倍 +2/+4/+6/+8/+10/+12。
- 属性%（力量/敏捷/智力/运气/HP/MP）：B 1%/2%/3%/4%；A 2%/4%/6%/7%；S 3%/6%/9%/10%；SS 6%/9%/12%/13%（按 0-30/31-70/71-150/151+ 分档）。
- 全属性%：A 1/2/3/4%；S 2/4/6/7%；SS 3/6/9/10%。
- 攻击力/魔法攻击力%（仅武器/副手/纹章）：B/A/S/SS 同属性%表。
- 攻击力/魔力固定值：B- +1..+6 / B +2..+12（同上分段）。
- BOSS 伤害%（武器/副手）：S 20%/30%，SS 30/35/40%。
- 暴击率%（武器/副手/纹章）：B 4% / A 8% / S 3..10% / SS 6..13%。
- 暴击伤害%（手套）：SS 5/6/8%。
- 无视防御%（主副武器/纹章）：B 15% / A 15% / S 30% / SS 35/40%。
- HP/MP 固定值：B- +5..+60、B +10..+125（按 10 级一档）。
- 移动/跳跃：B- +1..+4、B +2..+8。
- 防御力固定值（饰品/防具）：同 HP/MP 表。
- 技能 CD 减少（头部 SS）：-1秒/-2秒。
- 无敌时间（头部/套服）：A +1秒 / S +2秒 / SS +3秒。
- 技能类（S/SS）：帽子时空门、裤子神圣之火、手套火眼晶晶/急速领域、鞋子轻功/战斗指令。

### 3.3 与本端协议的关系
- 本端 `get_potential(i)` 返回的是**词条 id**（服务端 `PacketCreator:542-546` 发 5 个 short），不是数值。
- 客户端通过 `equip.potline.<id>` / `equip.spark.<id>` / `equip.soul.<id>` locale 映射成文案。
- 因此 wiki 公式的用途是：**生成/校对词条 id→文案表**（例如 id=1 "力量 +3" 对应 B- 41-50 档）。本端现有 12/10/5 条占位已是简化版，q3 决策为"用户提供完整文案表"，拿到后按此核对。
