## 结论
场景源必须用 nl::nx::Map001["Back"]["login.img"]["back"][scene_no]。
三张位图均带非零 origin，LoginBackground::set_scene() 已做
`scene_pos = pos + scene_sprite.get_origin()` 补偿，调用方传的仍是
「位图左上在窗口内的落点」，无需改动。
