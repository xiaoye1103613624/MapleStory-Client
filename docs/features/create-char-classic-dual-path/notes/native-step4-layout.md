## 5. 仍缺落点（决策点，不得伪装成原生常量）

1. `charSet` 绝对落点 `(323,150)` 是几何避让推导，置信度低；若取得原生 step4 截图或带
   `pos` 的 `NewChar*` 资源包，应优先按那份证据重校。
2. step4 与命名态的严格先后：IDA 只钉到 step4 存在；本轮依用户缺陷 3/6
   （「输入名字后角色与名字消失及外观/发色设置页缺失」）实现为
   **命名 → 外观/发色 → 建角包**，属流程推断。
3. `statTb` 的具体落点、`charAlert` 的显示时机无 xref，本轮 `statTb` 取角色右侧避让位，
   `charAlert` 不绘制。
4. `BtGenderMale/Female`、`BtHairSelect0..7` 在北斗运行时 img 中**没有专属按钮资产**
   （R6 精简包预期），本轮复用 `BtCheck` / `BtLeft` 位图作热区，属资源兜底而非原生资产。
