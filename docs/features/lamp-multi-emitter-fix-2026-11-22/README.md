# 多灯泡路灯 emitter 光源修复（2026-11-22）

> 分支：`feature/dev_0.0.1`
> 用户反馈："路灯素材中没有光源的发送位置吗？这个路灯的光源没有在三个灯泡上"
> 结论：**确认本端缺陷**。三灯泡灯（Henesys 型）本端只画了 1 个光源，原生有 3 个。

## 1. 根因（行号级）
- bundle 原始 `LAMPDEF`（lamps.cpp:43-48）：`int nEmitters; LAMPEMITTER aEmitters[4];`，`ApplyLamp` 循环 `for (int e=0; e<nEmitters; ++e)` 给**每个灯泡**放一盏光（lamps.cpp:942-955）。
- 本端原 `LampArt`（WeatherLamps.cpp:94）：只有单个 `int ox; int oy;`，`draw_one` 只画一个 glow → 三灯泡灯只亮 emitter0（中间），左右两个灯泡是死的。
- 精确数据来自 `weather_lamptable.inc`（generated by obj_lamp_emitters.py，逐像素测得的亮簇质心）：
  - henesys（acc1/grassySoil/space/21，lamptable.inc:39-40）：**3 emitter** `{ -5,-64,9 } { -28,-40,8 } { 19,-40,8 }`
  - 本端 `kLampArt[1]` 原本只有 `{-5,-64}`。

## 2. 本轮改动
`Weather/WeatherLamps.cpp`：
- `LampArt` 改为 `{ bank,dir,name,no, n_emitters, Emitter emitters[4] }`；`Emitter={dx,dy,radius}`。
- 5 型灯填全真实 emitter（逐字抄自 lamptable.inc:28/40/44/52/72）：
  - waitan(0):1 `{-4,-62,13}` / henesys(6):3 `{-5,-64,9}{-28,-40,8}{19,-40,8}` / kerning(8):1 `{20,-56,13}` / brazier(12):1 `{3,-74,3}` / ellinia(22):1 `{-8,-25,9}`
- `draw_one` 改为 `for (e < n_emitters)` 循环，每个 emitter 画两层径向 glow：
  - 外晕半径 `70 + radius*6`（13→148 / 8→118 / 3→88），内芯 `radius*3+10`
  - 全部走 `GraphicsGL::draw_glow`（独立渐变纹理，边缘 alpha→0，无矩形边）
- sprite 仍以 emitter0 为锚点绘制（保持既有对位，避免视觉回归）。

## 4. 真机验收清单（未验收，红线如实声明）

- [ ] 每个光晕在对应灯泡正上方，边缘平滑无矩形。
- [ ] 单灯泡灯（waitan/kerning/brazier/ellinia）行为不变，无重复光源。

## 5. 诚实边界
- **真机未验收**：清单需用户实机确认，未称"完全修复"。
- 本轮只覆盖本端手工表 `kManualLamps` 用到的 5 型灯；bundle 表里其它类型（magatia 2/nlc 3/candelabra 3/neon 4 等）本端未放置、无需改。
- 光晕大小按 emitter 实测 radius 分级近似，非 bundle `GLOW_R_SMALL/MEDIUM/LARGE` 逐档复刻（观感接近）。
