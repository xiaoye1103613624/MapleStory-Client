# T8 探针 opcode 拉黑名单
#
# 规则（硬门禁，写在 tools/probe/s9_probe.py 里，不由命令行绕过）：
#   1) 只有「s9 侧没有注册 handler」或「出现在 opcode_allowlist.txt」的 opcode 才可能被发出。
#      —— 「没有 handler」= Client.channelRead() 走 null 分支，只 updateLastPacket()，
#         对账号/角色/世界/数据库零影响（Client.java:207-236）。
#   2) 本文件是第二道否决：名字或值出现在这里的 opcode，即便满足 (1) 也一律不发。
#      要放行必须由用户逐条点名，并把放行理由写进 notes/probe.md。
#   3) 值一律 0x 前缀；名字取 s9 RecvOpcode 常量名。
#
# 取值依据：E:\project\BeiDou-Server_s9\gms-server\src\main\java\org\gms\net\opcodes\RecvOpcode.java
# handler 依据：同目录 ..\net\PacketProcessor.java（数组覆盖写，后注册者生效）
# 由 tools/gen_opcode_matrix.py 的 parse_java_enum()/parse_registrations() 现场解析校验，
# 本文件里的值若与源码不符，探针直接 ABORT（防止手抄错值导致误放/误拦）。
